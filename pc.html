电脑端

这是电脑端的部署与启动说明。Web 版不需要安装程序，解压后当静态站点运行即可。

进入电脑版 Web

一、本机直接运行

  1. 拿到构建产物：cradle-web.zip 或仓库的 dist/ 目录；
  2. 解压到任意目录；
  3. 用任意静态服务器指向该目录。
pnpm build
pnpm preview --host 0.0.0.0

然后打开 http://127.0.0.1:4173。不要直接双击 index.html，ES Module 和 Service Worker 需要 HTTP 环境。

二、部署到公网

  • Netlify Drop：把 dist 拖进网页即可；
  • Cloudflare Pages / Vercel：构建命令 pnpm build，输出目录 dist；
  • 自己的服务器：Nginx 指向 dist，未知路径回退 index.html。

上线后建议固定域名。Web 存档按“协议 + 域名 + 端口”隔离，换地址就是新存档。

三、桌面便携版

Windows 桌面直接运行 cradle.exe 便携版，存档在 %APPDATA%\dev.cradle.framework 或 exe 同级的 data 目录。

便携版和 Web 版存档不互通，两边各自独立。

四、注意

  • PWA 安装提示需要 HTTPS 或 localhost；
  • 首次加载后 Service Worker 会缓存界面，断网也能启动；
  • 内容包 zip 仍在游戏内手动导入。
