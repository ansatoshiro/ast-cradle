安卓 / iOS

手机不装 App 也能玩。电脑开服务，手机用浏览器打开，或者部署到 HTTPS 后添加到主屏幕。

进入手机版 Web

一、同一 Wi-Fi 直接玩

  1. 电脑在构建目录运行：
    pnpm preview --host 0.0.0.0
  2. 记下电脑局域网 IP，例如 192.168.1.2；
  3. 手机浏览器打开 http://192.168.1.2:4173。

打不开时检查 Windows 防火墙是否放行 4173 端口，以及手机和电脑是否在同一网段。

二、添加到主屏幕

  • iOS Safari：分享 → 添加到主屏幕；
  • 安卓 Chrome：菜单 → 添加到主屏幕 / 安装应用；
  • 局域网 HTTP 地址不会弹安装提示，但可以正常游玩；
  • 真正“安装”需要 HTTPS 域名。

三、部署到公网（推荐）

  1. 把 dist/ 部署到 Netlify / Cloudflare Pages / Vercel；
  2. 拿到 HTTPS 域名；
  3. 手机打开域名，Safari/Chrome 即可添加到主屏幕，离线启动。
pnpm build
# 把 dist 上传到静态托管

四、手机端注意

  • 存档走 IndexedDB，按域名隔离；换地址会变成新存档；
  • iOS 长期不访问可能清理站点数据，重要存档请导出备份；
  • 竖屏已适配，但小屏战斗按钮区域会内部滚动；
  • 便携版 exe 的存档不会同步到手机。
